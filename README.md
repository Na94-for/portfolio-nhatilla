# API Climática em Python

Aplicação desenvolvida em Python que consome a API do OpenWeatherMap 
para retornar dados climáticos em tempo real de qualquer cidade do mundo.

## O que o projeto faz

O usuário digita o nome de uma cidade e o sistema retorna:
- Temperatura atual em °C
- Sensação térmica
- Umidade do ar
- Descrição do clima

## Tecnologias utilizadas

- Python
- Biblioteca Requests
- API OpenWeatherMap
- JSON

## Aprendizados

- Consumo de APIs externas com Python
- Requisições HTTP com a biblioteca Requests
- Tratamento de respostas em formato JSON
- Boas práticas de segurança — remoção de credenciais sensíveis antes do versionamento

## Como executar

1. Instale a dependência:
```bash
pip install requests
```

2. Adicione sua chave de API no arquivo `clima.py`

3. Execute:
```bash
python clima.py
```
